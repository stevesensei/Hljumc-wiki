# （必读）如何获取黑大邮箱

因为认证站点开启了邮箱域名验证，强制要求必须以 `@s.hlju.edu.cn` 为结尾的邮箱域名进行注册，所以本篇文章用简单的方式告诉各位如何获取黑龙江大学的学生邮箱。

::: tip 本科生注意
有了这个邮箱，你可以申请工科相关专业的各种软件的学生认证。通过认证后，大学期间可以免费使用 JetBrains 系列软件等学生福利。
:::

## 一、登录邮箱自助申请系统

根据你的网络环境不同，有好几种方法。

### 1. 在校外或无法访问校园网的环境

1. 访问 [https://webvpn.hlju.edu.cn](https://webvpn.hlju.edu.cn)。

::: warning 证书提示
接下来你有可能多次遇到“你的连接不是专用连接”界面，请点击“高级”，然后选择“继续访问”。
:::

![访问 webvpn.hlju.edu.cn 时可能出现的证书警告界面。](/assets/email-webvpn.png)

2. 接下来登录你的统一身份认证。

![黑龙江大学智慧校园统一身份认证界面，包含账号密码、邮箱、通行秘钥选项和企业微信扫码登录入口。](/assets/email-identity.png)

3. 进入 VPN 之后，选择“邮箱注册”。

![邮箱自助服务系统界面，“邮箱注册”应用在办公协同分类中被突出显示。](/assets/email-register.png)

4. 进入邮箱自助服务系统，填写你的学号和手机号，随后点击登录。

::: warning 研究生遇到 mobile existed
如果你的硕士或者本科在黑大读书，提示邮箱申请失败，原因是 `mobile existed`，请点击“删除旧邮箱”链接处理。如果删除失败，请将新旧学号和需要绑定的手机号发送至 `2021034@hlju.edu.cn` 处理。以上内容节选自 2026 版黑龙江大学研究生教育管理信息系统新生入学相关业务操作手册。
:::

### 2. 在校园网环境

使用宿舍宽带、黑大智慧校园、黑大智慧校园-内网、黑大联通等网络时，直接访问 [regmail.hlju.edu.cn](https://regmail.hlju.edu.cn)，填写你的学号和手机号，随后点击登录。内网环境有可能无法正常登录，请参考上面的 VPN 方法。

这样，你的邮箱账号就是 `你的学号@s.hlju.edu.cn`。请记住这个邮箱，之后注册 HLJUMC 认证站时会用到。

## 二、使用企业微信管理邮件

从应用商店下载企业微信，使用注册邮箱的手机号注册，你会收到黑大的邀请。确认加入后，企业微信就有邮箱选项，你可以借此在手机上管理邮件。

对于网页端 [mail.hlju.edu.cn](https://mail.hlju.edu.cn)，也可以使用企业微信或者微信扫码登录。

![黑龙江大学邮箱登录页面，包含扫码登录、手机号登录和账号密码登录入口。](/assets/email-login.png)

## 补充内容

邮箱申请之后，建议校内老师、学术交流等环节如果要使用邮件交流，尽量使用这个邮箱，这样可能会更严谨一些。
