# 快速开始

如果你第一次加入 HLJUMC，按下面的顺序完成即可：

```mermaid
flowchart LR
  A[准备校园邮箱] --> B[注册认证账号]
  B --> C[创建游戏玩家]
  C --> D[上传并应用皮肤]
  D --> E[配置 PCL 或 HMCL]
  E --> F[进入 mc.hljumc.cn]
```

## 选择入口

- [进服指南](/quickstart/join-guide)：从注册账号开始，直到进入服务器。
- [启动器设置](/quickstart/launcher)：已经注册账号和玩家时，直接配置 PCL 或 HMCL。
- [如何获取黑大邮箱](/account/hlju-email)：没有 `@s.hlju.edu.cn` 邮箱时查看申请流程。

## 服务器是什么类型

服务器以原版生存为主。为了方便发展生电、减少重复劳动，服务端加入了一些辅助和性能优化 Mod；它们不是玩家进服的必装项，干净的 Minecraft 26.2 客户端也可以使用。
